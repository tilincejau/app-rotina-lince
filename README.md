# Rotina Lince

App para o celular que mostra se as automações da rotina diária deram certo (Nfe, Devolução, Vasilhames, Jornada,
Incentivo, DRE, RPS, Rota, Contas, GovLog...). Ele lê a planilha **Status rotina** do Google Sheets, que o PC
atualiza no começo da rotina, depois de cada automação e no fim.

O link da planilha **não fica no código**: cada celular cola o link na tela Configurar, e ele fica guardado só nele.

## Publicar (GitHub Pages)
1. Crie um repositório (ex.: `rotina-lince`) e envie estes arquivos para a raiz.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
3. Em 1–2 minutos o app fica em `https://SEU-USUARIO.github.io/rotina-lince/`.

## No celular
1. Planilha Status rotina → Compartilhar → Acesso geral: **Qualquer pessoa com o link** · **Leitor**.
2. Abra o endereço do app no Chrome → **Configurar** → cole o link da planilha → Salvar.
3. Menu ⋮ → **Adicionar à tela inicial** (iPhone: Safari → Compartilhar → Adicionar à Tela de Início).
